AIStable Diffusion

角色与摄影风格如何兼得：LoRA 人像实验续篇

前一篇先选择了构图相对固定的证件照。这次把目标换成更自由的人像摄影：光线、色调、环境和人物姿态都有变化时，还能不能保留稳定的人物特征？

原实验有公开人物与摄影作品作为示例。这里保留的是方法与对照结果，不把生成图当作真实摄影记录。

风格越强，身份不一定越稳定

我分别尝试了偏高曝光的清冷色调、暖色自然光，以及高饱和复古风。单独看风格 LoRA，它们都能产生明显变化；与人物 LoRA 组合后，问题才真正出现。

风格训练集里的人脸也被带进了结果。增加人物强度时，两种面部特征发生混合；继续增加，又可能让画面失真。两个强度相加，并不意味着两项能力可以独立叠加。

这里的问题也不同于普通图像风格迁移：我们不只是给一张已有照片换色调，而是在重新生成一个人像，同时要求身份与摄影语言都保持一致。

恢复原稿的暖色风格对照，便于与前面的清冷色调结果比较。

恢复原稿的复古风格对照；同一风格的稳定性仍需在多张结果上观察。

分层权重提供了更细的调节方式

实验尝试了 LoRA Block Weight。它允许对支持的网络块分别设置权重，而不只给整个 LoRA 一个统一数值。

但分层不等于获得了清楚的语义按钮。不能预先断言“这一层只管脸、另一层只管光照”。不同底模、网络结构、LoRA 和插件版本可能有不同的块布局与作用方式。

原笔记中的具体数组属于当时版本，因此这里不再把固定长度的数组当成通用模板。

恢复原稿中的插件界面。具体块布局与数组长度受版本影响。

用实验寻找有用的组合

第一种方法是逐块对照。固定检查点、提示词、采样参数和随机种子，仅改变一个块的权重，观察面部、背景、色彩和构图分别发生什么变化。

第二种方法是使用少量有代表性的组合做比较，再对有潜力的区域细调。这样比在一开始就尝试所有权重排列更实际。

评价也应分开：人物像不像、风格是否明显、画面是否稳定，以及换一个构图后是否仍成立。只看最好的一张，容易把随机抽中的成功误认为参数已经可靠。

原稿的逐块对照实验。固定其他变量，才能观察某个权重变化造成的差异。

原稿中的分层组合对照。它是当时条件下的实验结果，不是通用最优配置。

脸部修复不是无损修复

使用 ADetailer 一类工具，可以改善小脸、眼部或局部结构问题。但它会重新绘制局部区域，也可能改变身份、光照和皮肤质感。

因此，修复后的脸应该放回整体画面里判断，而不只看一个放大的面部裁切。局部更清晰，并不一定意味着整张照片更自然。

提示词与采样器也要放进对照里

原实验里，有些眼部描述、负面词和采样器组合确实产生了明显差别。不过这些观察依赖当时的底模与数据，不宜直接写成“某个词必然更真实”或“某种采样器一定更差”。

我更愿意保留一个方法：先固定已有效果的随机种子，一次调整一项参数，并记录版本。找到稳定区域以后，再换一批种子和构图测试泛化能力。

从后期调参回到数据设计

如果人物数据和风格数据从一开始就差异很大，后期调权重很难把所有矛盾消除。更一致的拍摄条件、更明确的数据标签，以及兼顾身份与目标风格的数据，会减少推理阶段需要补救的问题。

这次实验最大的收获，是看到“风格化”和“身份保持”并不是两项互不干扰的能力。分层权重提供了探索空间，而真正提高稳定性，仍然需要回到数据、底模和任务边界本身。
