    语音合成技术分类

    1.Text-to-Speech

    即 TTS。文本转语音，早期的TTS几乎和拨号按键的数字提示音一个效果，最基本的逻辑就是把文本每一个字都发音出来。诺基亚功能机时代手机内置的辅助功能是TTS，短视频配音里的小帅小美也是 TTS。

    在目前使用最广泛的TTS服务微软Azure的文档里，已经把它叫做“神经网络声音服务”。参考tts-state-of-art中介绍的在典型Benchmark数据集上截止到2022，的跑分排名如下：

    其中NaturalSpeech 和VITS 都是用了 variational autoencoder (VAE)模型。但也就是在几年上半年，微软在这一领域又发布了极高的进展vall-e

    虽然real-time的音色学习并不是什么新鲜概念，但是其优秀的泛化性和效果还是实现了这一领域新的突破，可以在官网听听他们提供的Demo。vall-e 虽然优秀，但目前仍然是闭源的，且并未完全集成到微软的对外服务，目前工程界可以使用到的流行的几种实现如下：

    ● 微软 Azure AI 语音 提供的 TTS 服务也是目前落地应用感知最多的 TTS 服务之一，前述中1的短视频“小帅”、“小美“等语音均来自微软提供的服务。

    ● bark 是目前TTS推理开源实现中star最多的项目之一，它强调Text-to-Audio即可以在声音中加入各种其他非文字声音，比如叹气，笑声，口头禅等，意在对 TTS 进行更好的人声模拟优化和真实音频场景优化，它本身主要提供内置的各种语音模型，效果对比微软的服务也非常不错，但是中文方面官网内置模型不太好，不过也可以用后面提到的vits来做训练得到自定义模型后放到bark中进行推理。

    ●vits 则是目前模型训练开源社区最繁荣的项目之一，比如目前围绕vits的开发社区中衍生了大量围绕二次元游戏领域的模型和工具，不过社区中目前数量最多的应该还是英文和日文预训练模型。

    2.Voice Change/ Voice Conversion

    即VC。声音转声音，可以理解成声音转换。虽然这一领域的落地场景没有 TTS 那么广泛直接，但有很多偏门的场景，也一直在发展和扩充想象空间，最近最火的应用就是“AI 孙燕姿”，TTS 输入是文本，如果要强调发音的自然，许多维持发音自然特性需要模型兼顾到，VC 输入本身是语音，可以理解为简化了一部分合成逻辑。在唱歌领域强调的是音色，音调，咬字特性等，落地场景可以很好的 契合。不过对 前面概念的TTS训练方式来说，最终应用场景不论音频作为输入还是文本作为输入其实差别没有那么大，譬如剪映中提供的特色声线既可以被用作 TTS 也可以被用做 VC。

    拿 AI 孙燕姿举例，其背后的模型是 GitHub - svc-develop-team/so-vits-svc: SoftVC VITS Singing Voice Conversion其生态也已经有了不错的发展，因此促成了 AI 歌手的一时火爆。

    理论发展情况

    语音合成发展从最初可以分为以下几个阶段：

    1. 基于语料库拼接合成
      需要大规模的真人音库，通过匹配拼接输出语音句子。

    2. 基于深度学习的参数合成
      用深度学习网络构造文本和音库之间的映射，其中的输入的中间结果涉及语言发音分析；输出的中间结果涉及声学参数，声学模型，通过声码器输出。

    3. 基于神经网络的端到端合成
      输入文本输出波形数据，跳过声码器。

    目前最新的模型比如Vits，微软的NaturalSpeech, Vall-e 都已经在第三个端到端的模型领域。

    在继续之前我们可以先理清下，语音合成效果好坏的标准是什么，目前比较常用的为Mean Opnion Score, MOS,其实还是一种人工从各个维度打分的方法：


    AI 技术测评 · TTS文字转语音

    这里我们简化一下这个评判标准：

    音色特色声线（无电音，人声音色接近真人） + 人声自然度（语气词，抑扬顿挫） + 情感

    自己动手

    如果要定制语音声线，目前使用最广泛的仍然是vits和sovits，其中后者是专门针对歌声的训练和推理方案，两者要发挥最大效果一般并不互相兼容。

    vits git 举出的训练集例子是LJSpeech Dataset，因为这个训练集很多情况下也作为测评集，数据比较规范，每个音频长度都在 1-10s无杂音。

    不过vits训练在开源社区也有许多其他训练脚本如：

    1.VITS-fast-fine-tuning

    训练集的准备可以提供各种音频甚至视频，需要将它们妥善分类，用不同的脚本去进行训练集的预处理来生成最终的音频和文本训练集，该项目也是目前使用最多的开源训练项目之一，项目内置了语音识别，分割，去噪等工具，整体训练流程十分方便。

    总结

    在一开始了解这个领域的时候，看到语音合成经常会被分成通用类和定制类，但实际上究竟什么是好的语音合成，完全是用户自己感知的，就像大模型在toC领域用户感知到的好坏，已经不完全是某个学术领域的定性定量指标了，用户感知虽然不是定性定量，但似乎又可以得出一个大概统一的标准。从chatGPT到AI孙燕姿到GPT语音，

    用户终于成为了那个难以琢磨但又结果明确的学术/技术评判指标。
