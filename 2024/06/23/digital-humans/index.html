    • 随着语言大模型的发展以及生成式算法的热潮，元宇宙时代的数字人概念如今又被赋予了众多有眼花缭乱的概念和应用，是真是假？是噱头是是机会？本文尝试从开发人员的视角为目前的数字人技术和市场进行综述，稍稍为这一领域理清脉络。

    本文先不打算为数字人下定义，先尝试为数字人从各个角度进行分类，在这些分类之下可以大概摸清什么样的产品会被套上数字人的概念。

    一、 数字人分类与案例

    1.1 驱动技术角度分类

    数字人使用的技术千差万别，从传统电脑CG到最近爆火的生成式，这里我们先从驱动和渲染两个角度，尝试把现有的主要数字人技术进行归类：

    驱动角度，从元宇宙时代到目前的生成式时代，最主要的一个技术流行趋势变化就是真人驱动到计算驱动，中之人的从有到无是目前提到数字人时的一个主流趋势。

    1.1.1 真人驱动

    上图中的例子分别为：

    • a: 凭借着动补设备价格的一波下沉，有中之人的数字人直播短暂流行过一段时间，
    • b: 除了专业的动捕设备，相机驱动 3D 形象的 AnimoJ 也引领了一段时间的虚拟形象潮流
    • c: 相机驱动另外一个成熟且自成体系的案例就是Live2D，其仍然是目前如B站这样的二次元社区流行的虚拟形象技术

    真人驱动技术的一部分发展可以看作影视级特效技术的不断下沉，在toC玩法和toB变现上已经经过了一轮比较成熟的发展，比如Live2D等仍然有很多的应用空间，但如今的 AI时代显然有了更受人追捧的概念：AI 与生成式，本文后续主要聚焦在计算驱动类型的数字人应用上。

    1.1.2 计算驱动

    上图中的例子分别为：

    • d: 英伟达发布会上的卡通3D虚拟黄仁勋
    • e: 2020年搜狗与新华社合作的写实3D虚拟主播
    • f: 特看的主要产品，虚拟卖货主播

    随着AI 技术在近年两年的爆发式增长，计算驱动的数字人成为了追捧的主流，尤其是生成式算法的发展，让数字人形象和驱动技术同时都有了全新的想象空间。后续章节将只主要以计算驱动案例为主要叙述对象。

    1.2 渲染技术分类

    基于审美风格，渲染类型可以分为 2D/3D，写实/卡通，最近HeyGen这类视频lipsync技术的大火，让 2D 写实类视频的数字人形式又重新流行。

    基于渲染技术，在传统 2D 和 3D 的基础上，结合最近因为Difussion模型收到追捧的生成式技术，产生了一些已经落地的靠生成式模型进行渲染甚至驱动的2D数字人，以及前沿的结合了生成式模型的 3D 重建技术。

    主流数字人渲染-2D

    依次为：

    • CG技术被IP类数字人多数采用，最大化视觉效果
    • Live2D （自成一派）
    • 生成式2D 图像，Difussion模型的流行使得形象的生产
    • 图片lipsync，如wav2lip为代表的一类lipsync技术，这类输入为图像的lipsync技术一直是目前成本最低的一种可定制化对话驱动技术，包括如更近的sadtalker,以及结合了新玩法的cahtAnything
    • 视频采集式嘴型生成,是最近大火的一类数字人概念

    主流数字人渲染-3D

    依次为：

    • 传统 3D，如Metaverse等
    • Nerf 为代表的新的3D技术如 Luma.ai
    • 生成式3D技术，如EG 3D，最新的还有如wonder3D，生成式算法被运用到 3D 重建中，用以提升建模效率，也是目前的一个研究热点。

    3D 渲染的数字人目前看整体仍然很受元宇宙时期遗风影响，前两年动捕设备的下沉，让 3D 数字人又泛起了一些新的水花，但最近很多之前做做 3D 数字人的公司开始发现投入更小，概念更新的 2D 数字人变得更加容易引起关注。

    基于审美风格的形象分类：

    • a: 妙鸭的Diffusion写实风格模型与 Lora 技术实现的数字形象，妙鸭的落地可以看作是一种新的“美颜”，基于Lora的实现使得以往的类似 GAN 的玩法变得更加粒度更加细化，譬如炼出一个帅哥美女 Lora，变成一种和以往参数美颜完全不同的思路，具体可以参考我在妙鸭推出之前就发布的文章如何使用AI画画一键参加朋友圈摄影比赛
    • b: 腾讯智影等最近又得到进一步推广的真人视频采集虚拟口播形象，这一技术得益于最近lipsync和tts技术的革新发展得到了效果和成本上的显著提升，这类视频采集式数字人成为了“最真”的数字人。
    • c: Live2D直播应用，Live2D作为一种虚拟形象方案有完整的生态和创作社区。是二次元形象最受追捧的虚拟形象载体，在某种意义上效果上的“不真实”超越了“真实”。
    • d: MetaHuman3D写实领域最佳效果之一的MetaHuman，在前一段时间流行的偏写实风的3D 游戏中，捏脸几乎成了一个标配，MetaHuman是这种捏脸效果的一个非常重要的参照。
    • e: 动漫风虚拟主播形象，动漫风的3D形象，比起写实3D实现，效果/成本的性价比要高很多，受众也更明确；而对比Live2D, 控制的自由度更高。
    • f: 596K的有中之人的虚拟主播codemiko，不完全是写实风格的 3D 形象，用一种打造 IP 的方式运营了该账号。

    1.3 驱动技术

    1.3.1 说话

    如何让数字人说话是敲定形象之后遇到的第一个驱动问题。在驱动问题上，目前的技术趋势基本也可以分为“生成式”和“非生成式”

    口型

    1.3.1.1 点位驱动

    例如微软tts服务提供了一套 2D矢量图点位标准和 3D blendshape权重查表标准：

    类似的还有苹果的animoj，只要遵循一套标准点位，嘴型就只是一种点位映射。

    1.3.1.2 嘴型生成

    主要是针对 2D 形象，不需要死板的通过遵循点位标准，直接每一个发音都替换掉图像上的嘴巴即可。目前开源项目中最热的有两个项目:wav2lip与video-retalking.

    wav2lip这里强行概括一下就是使用了类似表情迁移的 GAN，真实的发音嘴型作为评判标准，重新绘制嘴部迁移后的结果。

    对嘴部，准确的说是下半部分脸进行mask覆盖的inpainting, 重绘每一帧的嘴型。与该项目类似的还有DINet这类方法主要的区别在于如何优化 inpating 的突兀感，一般会在inpainting时对inpaiting部分或者整体加一个GAN来优化 inpainting 边界和模糊感。

    其他还有如结合了Nerf和3DMM人脸重建的嘴型重新渲染方法。

    发声

    这里现笼统的把数字人的发声概括为 TTS（本文这里也包括VC音色转换）。详细的TTS 技术概述可以参考我之前的这篇如何使用AI语音和偶像对话.但随着最近HeyGen在社交网络上的爆火，TTS 运用到虚拟人上的技术可以认为已经被分成了两类：

    1. 需要微调的带有语言特征预训练模型的深度学习模型。

    代表技术是vits利用深度学习网络端到端训练音频数据，音色克隆再进行。使用 1 小时左右的微调训练音频数据，T4卡训练1-2小时左右效果如下：allen_caixukun(2).wav（原音频待补）。

    2. 几秒音频无finetune, 零样本命中的多语言推理模型

    代表技术是VALL-E (X)，他使用了一般vits预训练模型使用的千倍以上规模的预训练数据，使得预训练模型本身可以in-context learning，几秒的音频作为prompt就可以推理克隆，项目和模型未开源，但根据论文可以倒推代码，接近vall-ex效果的体验公司有rask.ai和elevenlabs,最近大火的 heygen使用的就是来自elevenlabs的 tts 技术。（最近的OPEN AI TTS pretrain 应该使用了类似的思路）

    这里再详细说一下vall-ex,作为目前in context learning 零样本命中的最受关注的 TTS 技术：

    1. in context learning带来的zero-shot推理，几秒钟的音频可以带来效果极佳的推理
    2. 跨语言，极大的预训练数据规模，其可以容纳多语言结构的预训练模型，in context learning衍生的零样本命中推理，使其直接通过英文音频参数推理出中文音频结果。
    3. 充分借鉴了LLM 领域的一些架构（使用了Transformer结构）和训练集组织方式。训练集达到了之前的研究从未达到过的6 万小时音频数据。

    这要求对训练数据的纯度和质量都有较高的要求。目前有人论文倒推源码，但没有公认的开源预训练模型，开源社区几乎等量的英文训练数据尝试复现训练出模型，但效果比不上原始vall-ex demo。

    最新动态：

    xtts之前虽然也作为零样本命中项目，但效果不佳，与微软vall-ex效果相差很大，这周他们刚刚更新了v2版本的模型，效果提升了一个大台阶，虽然稳定性目前待验证，但已经非常接近vall-ex，或者elevenLabs的效果了。我录制了一个两分钟的chatGPT语音，当做prompts喂给xtts开源项目，输出的效果：chatGPT_clone（原音频待补）

    微软推出了Personal Voice的 TTS服务，可以认为终于让vall-ex的能力产品化了。

    因此在目前能看到的所有效果中，结合了最像真人的基于视频采集的嘴型替换技术以及in-context learning 的 TTS 技术，早就了目前最像真人的数字人，其中最成功的案例之一就是HeyGen,后面本文将用开源方案来尝试复现它。

    1.3.2 动作与表情

    说话可以是文字驱动或者音频驱动，在表情与动作领域，驱动输入远没有这么灵活。

    目前可以认为也被分为两类：

    1. 仍然使用图像作为输入驱动虚拟人动作，ontrolnet这类技术为代表，可以提取输入图像的动作信息，驱动虚拟形象。也包括众多传统的 3D 人体驱动

    2. 结合生成式算法，输入不再需要图像，典型的有如ActionGPT

    动作与表情的驱动，在 3D渲染领域，驱动输入虽然有一定限制，但也仍然可以通过自定义骨骼动画等进行定制，而在2D领域，除了自由度远不如 3D 的点位驱动，技术场景十分受限，目前仅有效果远不如真3D的 3DMM 点位重建，如sad-talker。另外就是目前正火的HeyGen为代表的视频采集式方案，人物动作只能限定在采集到的视频内容之内。

    1.4 应用类型分类

    功能与盈利模式分类

    从元宇宙话题时期开始，数字人在众多投资报告中从应用角度被分为两类：身份型和服务型，其中身份型应用和元宇宙时期的概念结合比较紧密，主要作为一种数字分身，强调定制化;服务型则作为工具类应用的延伸，数字人提供一种新的工具/服务交互界面。在盈利模式中toC和toB又属于两个不同的面向。

    • 身份型 x toB：IP 数字人是这一类场景的典型应用，他强调数字人形象的全面定制化和运营，本质上是一种内容产业，数字人IP目前最典型的变现方式就是像明星一样做营销向的商业合作。

    • 身份型 x toC: 这是元宇宙时期最典型的虚拟形象落地场景，最新打着数字分身概念的还有类似HeyGen的 Instant Avatart 功能以及妙鸭。

    • 服务型 x toB: 传统toB工具/服务 + 数字人界面，数字人可以作为真实服务人员的替代，或者作为服务友好交互的补充。在国内最具特色的落地场景就是数字人带货直播，视频采集式数字人也非常适合这一固定场景。除了HeyGen，国内提供类似服务的还有硅基智能和特看.

    • 服务型 x toC: 传统toC工具/服务 + 数字人界面，数字人主要提供更沉浸式（炫技式）的交互体验。这类toC服务目前主要的落地概念可能是AI 加持的咨询，个人助理，甚至虚拟恋人。

    生成式模型/TTS技术驱动落地

    在整个数字人领域，抛开元宇宙时期的概念，在以chatGPT和 Diffusion模型流行起来为分界点，产生了很多新的概念和追捧热点。下两图分别为1：图像Lipsync主题论文发表数量逐年趋势与2： TTS 主题论文发表数量逐年趋势。

    最近最热的HeyGen当属组合了这两个最近落地效果有极大进展的技术,

    和Diffusion模型结合起来的最近比较典型的案例还有：

    妙鸭：目前的发展暂时成为了一个之前 GAN 玩法的替身+新鲜的美颜效果，但其本人 Lora ID 的概念保留了后续作为数字分身发展的想象空间。

    衍生toB向的服务还有虚拟模特工作室。

    如何持续关注新技术的发展动态，不论是“新玩法”还是“新落地”，即使是只在社交网络上引爆舆论，也是一种成功。

    当红的视频lipsync技术如何真正演化成完全数字人概念必须跨越的一步，国内前面提到的厂商也尝试把其作为新的功能点，

    这套技术方案目前面临的一个主要问题是如何进一步扩展交互，面临以下两个问题

    2. 视频人物动作表情交互如何丝滑定制
      数字人整体渲染仍然是 2d ，人物动作表情只能机械化或者按照prompt视频反复，这项技术下的数字人，动作表情如何驱动如何适应场景仍然是一个比较空白的问题。

    2.2 开源复现

    1. TTS

    HeyGen使用了第三方TTS服务elevenlabs, 这一厂商也提供了类似vall-ex的零样本命中的TTS技术，所以可以用极短的音频做跨语言的 TTS。

    在开源领域，目前已知的有两个平替：

    1. 反推vallex官方的训练代码,项目本身没有提供预训练模型，但是开源社区内已经有人用微软论文提到的部分数据集进行了尝试复现，不过似乎目前分享出来的模型效果与官方 Demo仍然有较大差距
    2. xtts,这个开源项目之前在 TTS 领域就属于一直在被维护，且很早也含有零样本命中特性，不过其V1版本的模型零样本命中效果几乎不可用，但最近刚刚更新的 V2版本模型的效果有了很大的进步，比如这是我使用两分钟chatGPT语音文件作为prompt在该模型推理出来的效果（原音频待补）,已经非常不错，但多试一些样本之后发现稳定性还有待提高。但足见开源社区追赶落地产品的脚步之快。

    这是零样本命中推理，如果走传统的fintune路线，得到的效果会比较稳定，不过很难做到跨语言，具体的finetune复现方式仍然可以参考如何使用AI语音和偶像对话
