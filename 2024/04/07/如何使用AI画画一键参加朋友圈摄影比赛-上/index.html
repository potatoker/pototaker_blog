如何使用AI画画一键参加朋友圈摄影比赛(上)

有段子说旅行的终极目的已经变成了出图，有没有办法在家动动手指参加朋友圈摄影大赛？

靠近普通的人的场景是什么

大家应该已经对AI画画已经并不陌生了，也许你已经试过MidJourney,(感谢qq频道，就能很方便体验)，也许安装过StableDifussion，变成Prompt科学家可能需要点门槛，但多炼炼总能出图，手指轻轻一点，一张足够fancy的图就出现了。

然后就没有然后了。

作为一个已经感觉被时代抛弃的C端开发，总想着这些东西在C端究竟能如何落地呢？

Lora

在Diffusion模型的定制调优技术中，除了finetune,目前使用最多的一个技术叫做LoRA: Low-Rank Adaptation of Large Language Models，训练一个效果还不错的Lora, 只需要一台T4 GPU 8G显存的服务器，十几分钟就可训练完毕。真正实现人人有丹炼。

你可以使用Lora来指定Diffusion时的图像风格，也可以使用Lora来指定Diffusion时人物特性，包括人脸。目前在网上Lora最多的两个玩法就是“训练风格”和“训练任务/角色”

了解了Lora之后，可以在各类Lora分享平台上看看大家用Lora玩出了什么花样，比如C站汇集了各种不同风格的Lora。

写实风格的追捧

而二次元风格绘画应该目前是AI画画最接近能直接产生可用，有直接使用场景的领域。但如果你在持续关注C站会发现，炼丹师们的热情风潮已经渐渐从二次元领域转向三次元，这其中不仅是因为人们发现了Lora和finetune在不可描述领域的真实落地场景，我想也是因为真人/真实场景的领域模型调教还存在更大的发展空间，当然也更难，因为真实图像的瑕疵在普通人眼评判中会更加苛刻。

现在在C站上下载量排名第一的就是这个majicmix-realistic写实风格的finetune模型。后续我们将踩在这个巨人的肩膀上操作。

未了避免产出普通人可能只能赞叹一句fancy的图，我们把视野再拉近一点，我们出一些人人都能欣赏，人人都能评判的图。

比如前段时间小红书跟风火的“美式证件照”，大概长这个样子：

结合Lora目前角色+风格训练的应用场景，马上我们诞生了一个想法就是，训练一个“美式证件照”Lora, 再训练一个“自己作为角色”的Lora, 两者在一起使用，是否就可以动动手指跟上小红书潮人们的潮流趋势。

关于训练角色Lora, 推荐教程Generate Studio Quality Realistic Photos By Kohya LoRA Stable Diffusion Training - Full Tutorial ,关于训练风格Lora， 推荐教程Kasucast #13 - Stable Diffusion: How to train LoRA for Style | LoRA Part 1，训练Lora可以使用公司提供的平台AI Draw, 可以使用目前比较流行的webui ，而Diffusion跑图，当然建议使用最流行stable-diffusion-webui

关于这几个工具的step by step安装步骤，这里我简单列在了这里：小白step by step, 或者跟随上述视频教程即可。工具和教程齐活，可以开工了。

1. 训练数据集

1.1 训练角色数据集

  1. 人脸大小
    这里如果只用少量图，且目前大部分训练都适用的512*512图的情况下，对人脸在图像中的占比其实还是有一定要求的，否则，在分辨率有限的情况下，很难产出比较好的效果，可以参考下教程中，不过我也发现，这样的图像在达到一定数量之后，使用一些小比例图，也会更好的扩充后续Difussion出图时可选的人像大小。譬如前述教程中其数据集大概长这样：

  2. 人脸角度
    这里人脸角度也很重要，往往并不一定正脸才更像自己，也并不一定正脸才是最好看的那一个。同样也可以参考上面数据集的截图，这位作者使用了不同角度的人脸。

  3. 有无Caption
    caption是对每一张图片的文字标注，这里网上对角色数据集的图片caption该如何写，甚至是否要写有一些讨论，我这里的实践是写不写似乎在我现有的场景下差异不大。但后面的风格训练数据集还是强烈建议使用caption.

1.2 训练风格数据集

在训练风格中，我使用了小红书上各位潮人的po图。风格数据集其实有个很简单的确认方法：他们是同一种可以被你用类似文字总结的风格。更重要的注意事项是我后面列出的lora训练通用注意事项，但是由于我这里是用的风格图中含有大量的人脸，其实后面会发现这是“人脸”+“风格”会遇到的一个最常见的问题就是风格图中的人脸会影响人脸Lora的应用。所以针对我们这个场景，这里只有一个非常玄学的训练集准则：

2. 训练参数

这里我自己总结的一个通用注意事项是：

  1. 如果你是一个新手，一定要尽量使用默认参数。这是我的训练参数：

目前无论是训练任务和训练风格，我往往只会修改两个默认参数

  1. epoch num：这个数字越大，训练出来的风跟越明显，但是如果太大，也可能会产生过拟合，目前我自己的体验是10左右就差不多了

  2. ** Network Rank (Dimension) 和 Network Alpha**
    这两个值如果使用默认值，个人体验是产生不了太好的效果，在网上搜索，可以发现使用比较多的是128和200左右。

  3. repeat次数不一定越高越好
    这里图片repeat次数是指Lora训练时训练集img目录的数字前缀，一般认为训练集越纯，可以适当提高repeat次数，但目前我保持在40以下，甚至维持训练集图片数量不超过20，使用repeat也不超过20时产生的效果会比repeat次数更大时要好。

当然，比如前述教程中，还有对训练速率参数的调整等，也可以进行尝试。炼丹重在反复炼。

3. 推理时找到最合适的强度

训练过程中除了pompt词语本身的选取之外，最难把握的就是强度Lora应用的强度，如果训练对数据集的特性把握太弱，那么就无法得到想要那个有数据集特性的结果，但如果强度太高，就会使得结果过拟合，一旦prompt和数据集的描述有比较大的偏差，就会产生非常糟糕的结果。

当然上面的训练参数会影响这里的“特征”结果，而一旦训练结束之后，主要有下面两个变化量在影响特征强度：

  1. 模型epoch值
  2. prompt中对lora指定的强度

可以使用sd-webui的xy轴特性来观察各种强度组合下的效果，这个方法在前述教程Kasucast #13 - Stable Diffusion: How to train LoRA for Style | LoRA Part 1中有具体展现。

这里，我的建议是，待组合的Lora先单独确定一下强度，比如，我自己Lora大概长这样：

纵向是Lora在prompt中指定的强度，横向是model的epoch数，这里应该很容易理解，当epoch和strength越大，生成图会越靠近数据集，但是毕竟prompt无法完全还原数据集中的数据，最后过拟合的结果就是图像崩坏（声明，本人不长过拟合这样子）

这里可以观察到的一个特性是使用的Diffusion模型本身产生的人物人脸特征会随着角色Lora的强度增强以更小的权重融合到角色人脸中。这一特性在后续写实人像Lora + 写实角色Lora应用中会反复遇到。

这里基本确认了有效强度范围，比如这里我会选择epcho:5, strength：0.6作为这一Lora的适配强度。（虽然本人也不长这样）

注意事项

这里需要强调的是基于前文说的“融合”特性，在出图过程中，一定要善用seed, 原始图对风格Lora的影响十分有限，但是对同样有写实人物的角色Lora影响很大。当发现出图有固定问题瑕疵时，锁定seed再进行调整。

在目前没有进一步调整的情况下，可以看到仍然有以下问题：

  1. 人脸仍然有一定的涂抹感，这是现在很多写实风的通病，不过我们这次的证件照场景，本身的强对比度滤镜掩盖了这一缺陷
  2. 风格+角色融合后角色人脸特征多少会有丢失。（但也许大家就是想要丢失。。。）

当然基于我们的歪心思，很容易联想到另一种比较容易的方法就是“换脸”，是一个已经非常为人所熟知的技术。不过使用基于difussion Lora的方式，我们可以在不破坏整体风格的情况下随意指定prompt，包括动作，背景，表情，或者是否戴眼镜，一项技术全部搞定。这可能也是现在P图领域在diffusion模型问世之后得到发展的一种P图方式。
